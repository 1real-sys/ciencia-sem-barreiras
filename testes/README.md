Originais JPEG preservados, sem alteração de cores. Exibidos como “Fotografia” nos cartões públicos e do painel. As imagens dos cartões têm `alt=""` porque o nome do ambiente já está no mesmo cartão; o rótulo informa o tipo de mídia. Não são feitas identificações científicas dos organismos fotografados.

Solicitação de uso registrada nesta tarefa; autoria, licença específica e autorização institucional não foram informadas e não são presumidas. Não atribuir crédito inventado. Fundo do Rio mantém ilustração por não haver fotografia correspondente nesta entrega.

O build copia somente os oito JPEGs oficiais da tabela para `imagens/` no artefato, com URLs relativas compatíveis com o subdiretório do GitHub Pages. São capas padrão da interface; mídias editoriais continuam sob gestão do painel/Supabase.

Áudios, PDFs e demais fotos de teste nesta pasta não são incluídos automaticamente no site.
